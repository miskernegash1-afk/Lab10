Explain why creating tests can be useful in the process of software development.
Creating tests is very crucial because they help or it is very useful in software development because tests help programmers with their code work correctly. Indeed, when a programmer writes a function or a class testing can help them check whether the program the expected results. Especially it is very important to test the code in when a programmer later changes or adds code. In fact, a new code can sometimes new code can sometimes accidentally break existing code. As a result, testing the code after and before changing the code can helps programmers find problems early and make sure the program still works correctly.  For instance, from our textbook chapter 11 the get_formatted_name() function originally worked with the first and last name. When the function was changed to require a middle name, the original test failed. This showed that the new change broke the old behavior of the code. Indeed, the programmer fixed the code by making the middle name optional. Overall, testing helps find errors earlier, save time, and gives programmers more confidence that their software is working correctly.
